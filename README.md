# Сайт Екатерины Шамышевой

Одностраничный сайт начинающего гештальт-терапевта. Запись на индивидуальные консультации для взрослых — через [Telegram @myshShamysh](https://t.me/myshShamysh).

## Запуск

Нужны Node.js версии 22.22.0 или новее и npm. Для разработки подходит Node.js 24.

```sh
npm ci
npm run dev
```

Открой локальный адрес, который напечатает сервер.

Проект использует React, Vite, TypeScript и React Router в Framework Mode. Главная страница `/` пререндерится при сборке: текст страницы входит в HTML и доступен без выполнения JavaScript. Оформление — CSS Modules и CSS-переменные, переходы — CSS-анимации.

| Команда                | Назначение                                                                |
| ---------------------- | ------------------------------------------------------------------------- |
| `npm run dev`          | Запустить разработку с обновлением страницы при изменениях                |
| `npm run build`        | Собрать статический сайт в `build/client`                                 |
| `npm run preview`      | Открыть локальный предпросмотр готовой сборки                             |
| `npm run typecheck`    | Сгенерировать типы маршрутов и проверить TypeScript                       |
| `npm run lint`         | Проверить код через ESLint                                                |
| `npm run format`       | Отформатировать файлы через Prettier                                      |
| `npm run format:check` | Проверить форматирование без изменения файлов                             |
| `npm run check`        | Последовательно выполнить проверку типов, ESLint, форматирования и сборку |

## Изменение материалов

- `app/content.ts` — имя, роль, Telegram, заголовок и описание для поиска, навигация, темы запросов, шаги записи и ответы на вопросы.
- `app/routes/home.tsx` — остальные тексты страницы, стоимость, условия консультаций, границы практики и разметка секций.
- `app/routes/home.module.css` — оформление страницы и адаптация к размеру экрана.
- `app/styles.css` — общие стили, шрифты и CSS-переменные цветов.
- `app/components/marks.tsx` — декоративные SVG-иллюстрации.
- `app/assets/images/ekaterina-shamysheva.jpg` — фотография Екатерины в разделе «Обо мне».
- `public/` — файлы, которые попадут в сборку без изменений.

Тексты — рабочие черновики для согласования. Раздел «О подходе» объясняет гештальт-подход. Следующий раздел «Обо мне» объединяет фотографию Екатерины и общий список из шести пунктов: четыре об образовании и обучении, два о личной и групповой терапии. Ниже расположены разделительная черта и отдельный абзац о пути из IT в психологию, интересе к людям и желании помогать им находить опору. Первое образование Екатерины — в IT; она продолжает работать системным аналитиком. Заголовки оформлены без точек. Изображения дипломов пока не добавлены; получение ожидаемого диплома не подтверждено. Требования к практике, условиям консультаций и факты об образовании собраны в `AGENTS.md`.

Если меняешь цены или условия, обнови и текст страницы в `app/routes/home.tsx`, и поисковое описание `site.description` в `app/content.ts`.

## Домен и размещение

Домен и хостинг пока не выбраны. Для размещения нужен статический хостинг с HTTPS и собственным доменом. Node.js на хостинге не требуется.

Перед финальной сборкой скопируй `.env.example` в `.env` и укажи выбранный HTTPS-адрес, например:

```dotenv
VITE_SITE_URL=https://your-domain.ru
```

Это пример, а не адрес проекта. Значение задаётся **до** `npm run build`: оно используется для canonical, `og:url` и адреса в структурированных данных. Если адрес не задан или не использует HTTPS, эти URL не выводятся. После смены домена пересобери сайт.

```sh
npm run check
npm run preview
```

Загрузи содержимое `build/client` в корень сайта. Главная страница должна открываться как `/`, ресурсы — из `/assets/`. Для неизвестных адресов настрой обычный ответ HTTP 404 на стороне хостинга. Не включай перенаправление всех адресов на `index.html`: у сайта есть только один маршрут, а такое правило создаёт дубликаты главной страницы по произвольным URL.

В странице подготовлены заголовок, описание, Open Graph и структурированные данные Person; `public/robots.txt` разрешает индексацию. После выбора домена добавь `sitemap.xml` с окончательным адресом главной, укажи его в `robots.txt` и подключи сайт к Яндекс Вебмастеру. Проверку доступности страниц и индексации выполняют уже на выбранном хостинге.
