# Информация о проекте

Проект — одностраничный сайт-визитка Шамышевой Екатерины. На сайте представлять её как начинающего гештальт-терапевта.

## Задачи и аудитория

- Главное действие посетителя — написать в Telegram. Там договариваются о формате, времени и месте первой сессии.
- Аудитория — взрослые, преимущественно женщины. Работа индивидуальная.
- Источники посетителей: соцсети, личные рекомендации и поиск Яндекса. Учитывать поисковую индексацию при реализации.
- Сайт остаётся визиткой; блог, онлайн-оплата, календарь записи и административная панель в текущий объём не входят.
- Контент обновляет пользователь через код.

## Практика и условия консультаций

- Запросы: самооценка и самореализация; мужско-женские и детско-родительские отношения; тревожность; депрессивный опыт; выгорание и трудности на работе; кризисы.
- Не работает: с детьми и подростками; с парами и семьями; с РПП, ПРЛ, ПТСР; с химическими зависимостями; с тяжёлыми психиатрическими диагнозами; с сексуальным насилием; с тяжелобольными.
- Запросы об отношениях рассматриваются в индивидуальной работе со взрослым клиентом.
- Длительность консультации — 50 минут.
- Онлайн — 500 ₽.
- Очно — 700 ₽ плюс оплата кабинета. Центр Москвы, место по договорённости.

## Тон, дизайн и материалы

- Обращаться к посетителю на «ты». Тон спокойный и тёплый.
- Начальное визуальное направление: молочный фон; дизайн можно пересмотреть по обратной связи пользователя.
- Фотографии Екатерины есть; конкретные файлы ещё предстоит получить.
- Ожидается диплом о дополнительном профессиональном образовании. Не представлять будущий документ как уже полученный и не выдумывать сведения об образовании или квалификации.
- Тексты будут подготовлены позже; не считать черновики утверждёнными материалами.
- Домен и хостинг пока не выбраны; бюджет на обслуживание есть.

## Технический стек

- Утверждённый стек: React + Vite + TypeScript.
- React Router в Framework Mode с пререндерингом `/`: содержимое страницы должно попадать в HTML при сборке.
- CSS Modules и CSS-переменные для оформления; CSS-анимации для мягких переходов.
- ESLint и Prettier для проверки и форматирования кода.
- npm и package-lock.json для управления зависимостями.
- Статическая сборка; размещение на хостинге с HTTPS и собственным доменом. Конкретный провайдер пока не выбран.
- Дополнительные технологии и библиотеки сверх согласованного стека выбирать совместно с пользователем.

## Работа с Git

- Всё, что агент создаёт, изменяет или удаляет в рамках задачи, должно быть добавлено в индекс Git (`git add`) перед завершением работы над задачей.
- Добавлять в индекс конкретные файлы агента; не включать посторонние изменения пользователя без его просьбы.
- НЕ создавать коммиты без явной просьбы пользователя.
- НЕ выполнять push без явной просьбы пользователя.
- Просьба изменить файлы или добавить их в индекс не является разрешением на commit или push.
